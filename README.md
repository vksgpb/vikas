# Dr Vikas Kumar Singh — Academic Research Website

A free, responsive static website prepared for GitHub Pages.

## Preview locally

Open `index.html` in a browser. For the best local preview, run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish free with GitHub Pages

1. Create a free GitHub account if needed.
2. Create a **public** repository named `yourusername.github.io`.
3. Upload all files and folders from this website package to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. Your website will appear at `https://yourusername.github.io`.

## Personalise before publishing

- Replace `assets/portrait-placeholder.svg` with your professional photograph (keep the same file name, or edit the image path in `index.html`).
- Check the current role, timeline, email, ORCID and publication links.
- Replace the Google Drive CV link when a newer public CV is available.
- Add Google Scholar, LinkedIn and ResearchGate links when ready.
- The two project figures were extracted from the supplied proposal document.

## Files

- `index.html` — website content and structure
- `styles.css` — full visual design and mobile responsiveness
- `script.js` — menu, scroll animations and figure modals
- `assets/` — images and vector graphics
- `.nojekyll` — prevents GitHub Pages from applying Jekyll processing
